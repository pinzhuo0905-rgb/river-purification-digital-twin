# 河流光催化净化动态仿真程序 - 设计规格说明

## 1. 目标与范围
构建一个基于“微积分切片思想”与“指数衰减模型”的动态仿真程序，用于寻找河流光催化净化的最佳催化剂投放位置。该程序主要用于学术展示和效果推演，采用纯前端技术架构，使用户无需配置环境即可通过浏览器直接交互。

## 2. 核心系统架构
采用**纯前端架构**。
- **框架**: React (或兼容的现代前端框架)
- **可视化**: 
  - HTML5 Canvas：用于绘制 2D 河流浓度热力图和流向指示。
  - Chart.js / Recharts：用于渲染数据仪表盘（浓度随距离的衰减折线图等）。
- **计算层**: 纯 JavaScript 实现的数学引擎进行切片积分和最优解搜索。

## 3. 数学模型定义
- **微积分切片思想**: 将河流沿流向切割成长度为 $\Delta x$ 的无数微小切片。水流经过单个切片的停留时间 $\Delta t = \Delta x / v$。
- **指数衰减方程**: 催化剂作用下污染物浓度变化遵循 $C_{out} = C_{in} \cdot e^{-k \cdot \Delta t}$。
- **核心参数映射**:
  - 衰减系数 $k = \alpha \cdot I \cdot \eta_{catalyst}$。
    - $I$: 光照强度（输入变量）
    - $\eta_{catalyst}$: 催化剂效率系数（根据选择的催化剂种类如 TiO2 等映射为不同常数）
  - $v$: 河流流速。流速越快，切片停留时间 $\Delta t$ 越短，单次净化量小，但作用水域拉长。
  - **流向**: 决定了污染物在 2D 平面上的扩散矢量和计算轴线。

## 4. UI/UX 设计
界面核心包含两大模块：
1. **控制与数据仪表盘**:
   - **输入控制**: 流速（滑动条）、光照强度（滑动条）、流向（角度选择/转盘）、催化剂种类（下拉框）。
   - **指标展示**: 实时显示最大综合净化率，以及最优投放点坐标。辅以折线图展示污染物沿水流的衰减趋势。
2. **2D 仿真视图区**:
   - **热力图展现**: 渲染一条 2D 俯视的河流区域，用颜色梯度表示污染物浓度分布（如深色高污染，浅蓝低污染）。
   - **动态交互**: 当参数变化时，热力图即时更新。
   - **最优位置标记**: 系统计算出最佳投放位置后，在地图上用高亮标识明确圈出该坐标点。

## 5. 计算逻辑与流程
1. 初始化二维河流网格和初始均匀分布的污染物浓度。
2. 监听用户输入参数的变更。
3. 触发计算引擎：遍历可能的投放点作为起始点，沿给定的“流向”和“流速”运用切片衰减公式，积分计算下游的整体污染物剩余量。
4. 找出使得整体污染物剩余量最低（净化量最高）的初始投放坐标。
5. 将计算结果交由 Canvas 和仪表盘渲染。
