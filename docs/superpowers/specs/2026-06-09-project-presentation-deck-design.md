# 项目展示幻灯片（PPT）设计规格

> 日期：2026-06-09
> 目标交付物：一份用于向老师和同学展示「河流光催化净化动态仿真程序」的酷炫幻灯片，HTML 优先、可导出 .pptx。

## 1. 背景与目标

我们做了一个名为「基于微积分切片思想与指数衰减模型的河流光催化净化动态仿真程序」的项目。需要在课堂上向**老师 + 同学**展示，时长约 **15 分钟**，篇幅 **15–20 页**。

幻灯片要用**通俗易懂**的语言讲清楚：

1. **做这个项目的原因**（痛点 + 我们的答案）
2. **vibe coding 的介绍**（作为一条叙事暗线穿插在制作过程中）
3. **程序涉及的算法**
4. **算法背后的学科知识**

要求：逻辑连贯、视觉酷炫、并融合用户提供的「黄色小人（那个）」表情包风格。

### 成功标准

- 16 页幻灯片，内容覆盖上述 4 大主题，逻辑连贯。
- 视觉上延续程序自身的 iOS 液态玻璃美学，与现场 demo 无缝衔接。
- 黄色小人作为吉祥物贯穿全场，按内容切换表情，趣味适度、不喧宾夺主。
- 可全屏键盘演示；可导出为一份便携 .pptx 交给老师。

## 2. 决策记录（已与用户确认）

| 决策项 | 选择 |

| meme 浓度 | **适度点缀**——整体专业，小人作吉祥物贯穿，关键处玩梗 |

## 3. 技术实现方案

### 3.1 HTML 幻灯片
- **单文件、自包含、零运行时依赖**的 HTML（内联 CSS + JS）。
- 输出位置：`presentation/index.html`（配套 `presentation/assets/` 放截图与小人素材）。
- 导航：键盘 `←` `→` / `空格` 翻页，`F` 全屏；右下角细进度条；页码指示。
- 每页为一个全屏 section，入场用轻柔 `fadeInUp`（遵循 `prefers-reduced-motion`）。
- 背景：轻量 Canvas/WebGL 流体水波，缓慢漂移、低成本，不持续高负载。

### 3.2 导出 .pptx
- HTML 完成并人工确认后，用无头浏览器（可借助本地预览工具）把每页渲染为高清 PNG（1920×1080）。
- 用 `anthropic-skills:pptx` 把每张图作为满版背景拼成 16:9 的 .pptx，一页一张图。
- 输出位置：`presentation/项目展示.pptx`，与现有 `project_presentation.pptx` 区分（不覆盖）。

## 4. 视觉规格（复用程序 DESIGN.md，保证与现场 demo 统一）

- **配色**：背景水雾 `#eef7ff → #f8fbff`；主蓝 `#007aff`、青 `#32ade6`、薄荷 `#34c759`；柠檬黄 `#ffcc00` 呼应小人；黄橙红仅用于污染 / 风险 / 提醒状态。禁止大面积深蓝黑赛博风。
- **玻璃面板**：半透明白底（`rgba(255,255,255,0.62)`）+ `backdrop-filter: blur(14px) saturate(150%)` + 细白边 + 柔和蓝色投影 `0 24px 70px rgba(0,122,255,0.14)`；圆角 18–24px。
- **字体**：`"Noto Sans SC","PingFang SC", Inter, -apple-system, sans-serif`；数字与公式用 Inter。页面标题 800 字重、可加极轻蓝绿渐变；不用强投影/强霓虹/负字距。
- **算法 / 数据页**：借用"大字报"排版——公式特大居中、关键数字爆点显示（如 `e^(−kt)`、`C_final < 10%`）。
- **状态色语义**：蓝=主操作/计算焦点，薄荷=达标/净化，青=河流/数据流，黄橙红=污染/风险。

## 5. 黄色小人吉祥物

- **角色定位**：贯穿全场的"导游吉祥物"，多数页面出现在角落，按内容切换表情。
- **表情集合**：清爽、略浑、难受、高污染（来自 DESIGN.md 的污染探针四档）+ 思考、笑、惊叹、挥手。
- **素材方案**：
  - **首选**：使用用户提供的 4 张原图，放入 `presentation/assets/mascot/`。
  - **兜底（默认）**：若拿不到原图，用 CSS/SVG 复刻一个同款黄色小人，并用滤镜/变形近似不同表情。
- **与程序的呼应**：明确点出"这个小人其实就是程序里的污染探针小人"，让 meme 与项目本身形成闭环。

### vibe coding 叙事线
第 4–5 页集中讲，封面后引入，结尾（第 16 页）再呼应一次。语气轻松、真实，体现"人提想法、AI 落地、快速迭代"的协作模式。

### 算法讲解原则
所有算法均按"**先讲直觉 → 再给公式 → 最后连到学科**"的顺序，通俗优先。公式只保留最关键的一两个，配直观图示，不堆推导。

## 8. 范围与非目标（YAGNI）

- **做**：16 页 HTML 幻灯片、WebGL 水波背景、小人吉祥物、算法/学科内容、真实截图、导出 .pptx。
