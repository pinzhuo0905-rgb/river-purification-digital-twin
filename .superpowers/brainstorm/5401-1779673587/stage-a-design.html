✅ 集成式（推荐）：backend/ 子目录 + 一键启动

在现有项目根目录下新建 backend/，用 concurrently 一条命令同时跑前端 Vite + 后端 Uvicorn，像现在一样 npm run dev 就全启动。

📁 新的项目结构
项目根目录/ ├── src/　　　　　　　　（前端，不动） ├── backend/　　　　　　NEW │ ├── main.py　　　　　NEW　FastAPI 入口 │ ├── database.py　　　NEW　SQLite 连接 │ ├── models.py　　　　NEW　数据表定义 │ ├── schemas.py　　　 NEW　Pydantic 验证 │ ├── scenarios.db　　 NEW　SQLite 数据文件 │ └── requirements.txt NEW ├── package.json　　　　MODIFY　加 concurrently └── vite.config.ts　　 MODIFY　加 API 代理
🚀 启动方式
$ npm run dev　　　　# 一条命令同时启动前后端 　　　　　　　　　　# Vite: http://localhost:5173 　　　　　　　　　　# FastAPI: http://localhost:8000
为什么推荐这个？ Vite 的 proxy 配置让前端的 /api/* 请求自动转发到后端，开发时完全感觉不到跨域问题。阶段 B 加计算引擎、阶段 C 加 WebSocket，都在同一个 backend/ 目录里扩展即可。
B

🔧 分离式：独立后端项目 + 两个终端

后端作为一个完全独立的项目（甚至可以单独建一个文件夹），前后端各自手动启动。代码彼此完全解耦。

📁 项目结构
河流仿真前端/　　（当前项目，基本不动） 河流仿真后端/　　NEW 独立目录 ├── main.py ├── database.py ├── scenarios.db └── requirements.txt
🚀 启动方式
终端1：$ npm run dev　# 前端 终端2：$ uvicorn main:app --reload　# 后端
适合场景：如果你打算把后端单独部署到服务器（阶段 B/C 时），分离式天然就是对的。但本地开发时需要同时开两个终端，稍微麻烦一点。
